Let's Go Shopping
=================

A money-sense board game for kids (ages 6-10).
Shop with friends, then cook a meal together.

HOW TO PLAY
-----------
1. Unzip this folder.
2. Open a terminal (or command prompt) inside this folder.
3. Run:        python3 -m http.server 8000
   On Windows: py -m http.server 8000
4. Open your browser and go to http://localhost:8000

Even easier:
  Mac / Linux : double-click START-HERE.command
  Windows     : double-click START-HERE.bat

NOTES
-----
- The game is a static web page. No internet is needed after unzipping.
- It works best on a tablet or computer, in landscape (wide) mode.
- On a phone, the game will ask you to turn it sideways.
- No login, no ads, no real money. Everything stays on your device.
